AI agent

Isagawa Kernel

Given
an AI coding agent working for hours, across restarts
When
it tries to skip a step or repeat a past mistake
Then
hooks block the action, every failure becomes a permanent rule, and the agent never grades its own work

Open source under MIT. Runs my own agent workflows every day.

LLM and agent evaluation

When

Then

AI verification

Agent run attestation

Given
an agent pipeline run
When
it finishes
Then
what it was asked, what it did, and what it produced are signed with Sigstore and recorded in the public Rekor transparency log

Agent runs are signed and recorded on a public log. Anyone can verify them without trusting the agent or me.
